# Device Information & Status Commands
1. GET_BATTERY_STATUS - Check current battery percentage and charging state.
2. GET_BATTERY_HEALTH - Retrieve battery health and condition.
3. GET_BATTERY_TEMPERATURE - Read the current battery temperature.
4. GET_BATTERY_VOLTAGE - Read the current battery voltage.
5. GET_WIFI_STATUS - Check if Wi-Fi is enabled or disabled.
6. GET_WIFI_SSID - Get the name of the connected Wi-Fi network.
7. GET_WIFI_LINK_SPEED - Get the current connection speed of the Wi-Fi.
8. GET_WIFI_SIGNAL_STRENGTH - Retrieve the RSSI of the Wi-Fi connection.
9. GET_DEVICE_MANUFACTURER - Get the device hardware manufacturer.
10. GET_DEVICE_MODEL - Get the specific device model name.
11. GET_OS_VERSION - Check the Android OS version.
12. GET_API_LEVEL - Get the Android API level.
13. GET_UPTIME - Check how long the device has been running since the last reboot.
14. GET_CURRENT_TIMEZONE - Get the device's configured timezone.
15. GET_STORAGE_TOTAL - Get the total internal storage capacity.
16. GET_STORAGE_AVAILABLE - Get the remaining available storage.
17. GET_RAM_TOTAL - Check total physical memory on the device.
18. GET_RAM_AVAILABLE - Check available free memory.
19. GET_IP_ADDRESS_LOCAL - Retrieve the local IP address on the network.
20. GET_MAC_ADDRESS - Retrieve the network adapter MAC address.
21. GET_BLUETOOTH_STATUS - Check if Bluetooth is enabled.
22. GET_NETWORK_TYPE - Check the active data connection (Wi-Fi, LTE, 5G, etc.).
23. GET_SCREEN_BRIGHTNESS - Get current screen brightness value.
24. GET_VOLUME_MEDIA - Get the current media playback volume.
25. GET_VOLUME_RINGTONE - Get the current ringtone volume.
26. GET_VOLUME_ALARM - Get the current alarm volume.
27. GET_INSTALLED_APPS_COUNT - Count total installed third-party apps.
28. GET_SYSTEM_APPS_COUNT - Count total system apps.
29. GET_LANGUAGE - Retrieve the current system language setting.
30. GET_FONT_SCALE - Check the system font scale setting.

93. ENABLE_BLUETOOTH - Attempt to turn Bluetooth on.
